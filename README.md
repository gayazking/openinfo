# 🌍🔥 Эль-Ниньо: Карта Пиздеца

Интерактивная мобильная карта того, что **Эль-Ниньо** (и его сестра **Ла-Нинья**)
устраивает на планете — по континентам, странам и годам. Выглядит как детская игра,
но построена полностью на реальных климатологических данных.

👉 Открой `index.html` в браузере телефона. Зависимостей и сети не требует — всё работает офлайн.

## Что внутри

- **Карта мира** (176 стран) красится «индексом пиздеца» 0–100: от 😌 *спокухи* до 🫠 *ПИЗДЕЦА*.
- **Таймлайн 1950→2035** — ползунок и кнопка ▶ автопроигрывания. Видно, как очаг
  бедствия гуляет по континентам от события к событию.
- **Мини-график ONI** под слайдером — реальный индекс: 🟧 Эль-Ниньо, 🟦 Ла-Нинья.
- **Тап по стране** — сводка: какие катаклизмы (засуха 🏜️, наводнения 🌊, пожары 🔥,
  циклоны 🌀, крах рыболовства 🐟, неурожай 🌾, оползни ⛰️, гибель кораллов 🪸 и др.),
  насколько жёстко и почему.
- **Рейтинг топ-пиздеца** по выбранному году.
- Быстрые кнопки на легендарные годы: 1982, 1997, 2010 (Ла-Нинья), 2015, 2023.

## На каких данных

| Слой | Источник |
|---|---|
| Индекс **ONI** (Niño 3.4), 1950–2025 — фактические наблюдения | Таблица ONI NOAA Climate Prediction Center (ERSSTv5) |
| Телеконнекции воздействий по странам | Ropelewski & Halpert (1987); Cai et al. (Nature, 2014–2023); NOAA/IRI ENSO impact maps; WMO ENSO Update; задокументированные события 1982-83, 1997-98, 2015-16, 2023-24 |
| Геометрия стран | Natural Earth (упрощённая, 110m) |
| 2026–2035 | **Сценарий, не прогноз** — амплитуда усилена под вывод о росте частоты экстремальных Эль-Ниньо при потеплении |

ENSO нельзя предсказать на годы вперёд: всё после 2025 — иллюстрация, а не прогноз.
Это просветительский инструмент и качественная модель воздействий, а не точечный прогноз
для конкретного места. Для решений — оперативные бюллетени NOAA / WMO / Росгидромета.

```

assets/css/styles.css    # стиль «детская игра», мобайл-фёрст
assets/js/world.js       # геометрия стран (GeoJSON → компактный JS)

assets/js/oni.js         # ряд ONI 1950–2035 + классификация фаз
assets/js/impacts.js     # модель импактов по странам + расчёт индекса
assets/js/app.js         # проекция, рендер карты, таймлайн, интерактив
```

## Как устроен «индекс пиздеца»

Для каждой страны заданы поражающие факторы отдельно для фаз Эль-Ниньо и Ла-Нинья
с весами по силе. Индекс = `база + Σ(вес × |ONI|)`, нормированный в 0–100 и
разбитый на 5 уровней. Чем сильнее ENSO в выбранный год (по реальному ONI),
тем ярче загораются чувствительные регионы.
